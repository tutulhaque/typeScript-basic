# TypeScript Overview

## What is TypeScript?

TypeScript is an **object-oriented programming language** built on top of **JavaScript**.  
It adds **extra features** such as static typing and better tooling support.

In **JavaScript**, object-oriented programming is **not strictly supported by default**.  
Instead, we write object-oriented–style code using **syntactic sugar** (like `class`) provided by JavaScript.

---

## TypeScript’s Own Types

TypeScript introduces several built-in types that do not exist in plain JavaScript:

- Interface
- Void
- Array
- Tuple
- Enum
- Union
- Intersection

---

## Drawbacks of TypeScript

- **Type Complexity** – Types can become difficult to manage in large projects
- **Limited Library Support** – Some libraries lack full TypeScript definitions
- **Over-Engineering** – Small projects may not need TypeScript’s extra structure
- **Migration Challenges** – Converting existing JavaScript projects can be time-consuming
